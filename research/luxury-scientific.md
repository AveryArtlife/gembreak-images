- Survivors share one shape: **an uncommon, dictionary-real, Latin-rooted quality adjective +
  a sober scientific noun** (Criterion, Exemplar, Sovereign …). The re-sweep was built on it.

## Method

DNS `NS` query per name against 1.1.1.1 / 8.8.8.8 / 9.9.9.9 (fallback 9.9.9.9 /
208.67.222.222), 4 attempts; authoritative **NXDOMAIN = DNS-open lead**; SERVFAIL/timeout =
unverified, never guessed. Collision screening by web search (sources logged in the session);
"none found" means no obvious web collision — **it is not trademark clearance.** Run a USPTO
knockout (Classes 5, 35, 44) on CRITERION before building.
