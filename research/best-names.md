# Best Names — After a Brutal Stress Test

**Updated:** August 15, 2026 · Companion to `peptide-domain-research.md`

The earlier shortlist was run through a **hostile trademark / collision / linguistics screen** — every name searched for reasons to *reject*. Most did not survive. What follows is only the names that did, each with the specific flaw that keeps it off a "perfectly clean" rating, plus availability across **`.com` `.ai` `.io` `.gg` `.club`**.

> **Read this first — two hard truths from the screen:**
> 1. **`[Word] Peptide` is structurally weak.** The second word is generic and unprotectable, so you're really trademarking the first word alone — and the peptide space is swarming with "research use only" grey-market vendors, so *regal/imperial/royal/prime* styling reads as a research-chem storefront.
> 2. **None of the survivors are 100% clean.** Each is "least-fatal," not "clear." Before committing to any one, run a formal **USPTO knockout search (Class 5 supplements / Class 31 pet, Class 44 telehealth)** and a live domain + social-handle check. This document is a screen, not legal clearance.

## What got cut, and why (so you don't revisit them)

| Name | Killed by |
|------|-----------|
| **Peptovi** | **Peptivo.com** — an existing peptide/GLP-1 telehealth brand, one letter off (i↔o). Indistinguishable when spoken. |
| **Peptura** | The name **is already a live grey-market research-peptide vendor** (peptura.org/.us) — "research use only, not for human consumption." |
| **Imperial Peptide** | **"Imperial Peptides"** already exists as a cluster of grey-market vendors (US + UK). |
| **Regal Peptide** | Grey-market-coded ("Royal Peptides" is a vendor) + Regal Labs sells supplements. |
| **Lantern Peptide** | **Lantern Pharma** — a *public* clinical-stage oncology biotech (NASDAQ: LTRN). Direct TM exposure. |
| **Cobalt Peptide** | Cobalt is a **toxic heavy metal** ("cobaltism," cardiotoxic) — a poison-metal name on an ingestible + Cobalt Pharmaceuticals. |
| **Meridide** | Unspellable on hearing (MER-ih-dyde? meh-RID-ee?); the "-ide" ending sounds like a chemical, not a brand. |
| **Pupitide** | **FATAL — "Puptide" already exists** (takepuptide.com): a real dog peptide + NMN longevity supplement. Same niche, one letter apart. |
| **Collapup** | Reads as **"COLLAPSE."** Catastrophic for a longevity brand. |
| **Pawllagen** | Radio test fails (nobody spells the double-L) and the paw+collagen pun is already a category cliché (Pawable Collar-Gen, PawLabs). |
| **Best Boy Labs** | "Best Boy" is a film-crew title; "Good/Best Boy" is the single most saturated trope in dog supplements. |
| **K9 Renew / Good Boy Vital / Snout Vital** | "K9", "Good Boy", and "Snout"/"Vital" spaces are wall-to-wall — generic, weak, undifferentiated. |

## The best names — humans

All five are **available across every requested TLD**. Ranked by *least-fatal* per the screen. The "peptide" in the string is optional — see the note above; a coined/arbitrary name you can fully own is strategically stronger if you can clear one.

| Rank | Name | `.com` | `.ai` | `.io` | `.gg` | `.club` | The one caveat to clear |
|------|------|:--:|:--:|:--:|:--:|:--:|-------------------------|
| 1 | **Harbor Peptide** | ✅ | ✅ | ✅ | ✅ | ✅ | Only hit is **Harbour BioMed** — foreign, British "Harbour" spelling, antibody drugs (not consumer). Cleanest radio + vibe of the set. |
| 2 | **Ridge Peptide** | ✅ | ✅ | ✅ | ✅ | ✅ | No consumer-peptide collision; Ridge Bio/Pharma are B2B. Watch: **Ridge Wallet** owns DTC "Ridge" recall; a touch generic. |
| 3 | **Cedar Peptide** | ✅ | ✅ | ✅ | ✅ | ✅ | Premium, calm, effortlessly spellable. Watch: "Cedar" is crowded in health (Cedar Inc, Cedar Pharma) and reads generic-spa. |
| 4 | **Sable Peptide** | ✅ | ✅ | ✅ | ✅ | ✅ | Luxe, short, memorable. Watch: **Sable Therapeutics** is a science-beauty brand in your skincare adjacency — closest collision. |
| 5 | **Kindred Peptide** | ✅ | ✅ | ✅ | ✅ | ✅ | Warmest/most distinctive. Watch: **Kindred Healthcare** (large) + **KindredBio** (biopharma, bought by Elanco) — clear carefully. |

**Pick order:** if you want the safest, most ownable name → **Harbor Peptide**. If you want warmth/personality and will pay for a careful clearance → **Kindred Peptide**. If skincare is the wedge → avoid **Sable** (Sable Therapeutics) and take **Cedar**.

## The best names — dogs

The dog pool was gutted (Pupitide and Collapup were fatal). These four survived the screen clean and are **available across every TLD**. The **"-cell"** names carry a real advantage: "cell" reinforces a *cellular-longevity / peptide* story instead of undercutting it.

| Rank | Name | `.com` | `.ai` | `.io` | `.gg` | `.club` | Why it survived |
|------|------|:--:|:--:|:--:|:--:|:--:|-----------------|
| 1 | **Pupcell** | ✅ | ✅ | ✅ | ✅ | ✅ | **USPTO-clear** (no "Pupcell"/"Pup Cell" mark). Cleanest slate in the whole study; "cell" is on-theme. Only soft note: style the wordmark so it doesn't read "pup-sell." |
| 2 | **Houndcell** | ✅ | ✅ | ✅ | ✅ | ✅ | No brand collision found; same cellular-longevity theme as Pupcell, slightly more grown-up ("hound" vs "pup"). |
| 3 | **Puprenew** | ✅ | ✅ | ✅ | ✅ | ✅ | No collision; "renew" squarely on-theme for longevity. Style as **PupRenew** to avoid the faint "…ew" tail. |
| 4 | **Foreverhound** | ✅ | ✅ | ✅ | ✅ | ✅ | No collision; clean longevity promise, easy to say/spell, premium enough for a longevity price point. |

> Dropped on re-check: **caninecell** — too close to the existing **Canine Red Cell** supplement.

**Pick order:** **Pupcell** is the standout — it's the single cleanest name in the entire study and the "-cell" story ties directly to peptides/longevity. **Houndcell** is the natural sister brand if you want a more mature tone.

## Availability method (this round)

Each name was queried for an `NS`/`SOA` record against public resolvers for **every TLD** (`.com/.ai/.io/.gg/.club`); an authoritative **NXDOMAIN = available**. Verified with a second independent resolver + record type (controls `claude.ai`, `openai.io`, `dan.gg`, `get.club` all correctly returned *taken*). Collision findings came from live web/trademark searches; see the source links in the two research passes. **Availability shifts daily — confirm at purchase, and clear the trademark before you build.**
