> ## ⚠️ Read this about "available" (methodology correction)
> This environment has **no authoritative registry access** (RDAP and WHOIS/port-43 are firewalled) — only DNS. So "available" here means **"has no nameserver delegation"**, which is a strong *lead* but **not a guarantee**: a domain that's registered-but-parked-with-no-DNS (e.g. **malibupeptide.com**, which looked open but is actually taken) reads the same as a truly free one. The signal reliably identifies **taken** names (they have nameservers) but the "available" set is a **grab-check list** — confirm each in a registrar's search box before buying, exactly like sohopeptide.com was. Treat every "available" name across this whole study the same way.
