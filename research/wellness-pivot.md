## Method

Same as all prior rounds: `NS` query per name against 1.1.1.1 / 8.8.8.8 / 9.9.9.9 (fallback
9.9.9.9 / 208.67.222.222); an authoritative **NXDOMAIN = DNS-open lead**; SERVFAIL/timeout =
unverified, never guessed. Availability shifts daily — confirm at purchase; run a USPTO
knockout (Class 5 supplements, Class 44 health services) before building on any name.
