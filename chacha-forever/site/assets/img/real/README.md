Rules:
1. **`CONFIG.SHOW_REAL_PHOTOS` in `site/app.js` is `false` by default.** The hosted copies only render when it is `true`. Flip it after one of: (a) written permission from Rebecca Belote's family, or (b) a decision by the project owner to run credited editorial-style use and accept the takedown risk. The Instagram embed of Complex's post shows the real photos without hosting them and is on by default.
2. Never crop, filter or caption the real photos as memes. Memes use the character.
3. Never publish the photo of Cha Cha with the family's son. He is a minor. It is not in this folder on purpose.
4. Always render the credit line under the photo.
